모델 영향

  • 임계 변경 없음 (3Q26 연결 영업이익 X = -41억 이상이면 유지·추가매수 검토 / Y = -60억 미만이면 논지 폐기, 보조 매출 ≥1,400억 유지).
  • 이유 ① 분해가 임계를 뒷받침함: 2Q26 연결 -61.5억 = 한국 +23.4억 + 필리핀 -85.0억(+연결조정). Base -41억은 한국 +20~25억 유지·필리핀 손실 -65억 안팎으로 축소(2Q 이관비용 소멸)를 뜻하고, Bear -60억은 필리핀 -85억 지속과 같다. v3의 Base/Bear 산식과 모순이 없어서 숫자는 그대로 둔다.
  • ② 삼성 비중 72~75% 확정은 v3 가정(≥50%)보다 집중도가 높음 → 민감도①의 '단가 ±10%' 충격이 실제로는 삼성 1사 협상 결과라는 뜻. 방향은 Bear 쪽 리스크 확대지만 3Q 임계값 산식 입력은 아님.
  • ③ 테스트 램프가 브로커 당초 일정(7월 월 130억)보다 약 4개월 늦어짐 → v3의 "11월 1단계, 4Q 테스트 증분 30/70/120억"은 이미 지연을 반영한 값. 추가 하향 근거는 없음.
  • ④ 컨사인 장비(SK 단일)가 맞다면 테스트 증분 마진은 v3 가정 35~50%의 상단 쪽. 다만 계측기 자체 취득 296억과 상충해 반영하지 않음.
  • 추가 점검 항목(임계 아님): 3Q 분기보고서 영업부문 주석에서 필리핀 부문 영업손실이 -85억보다 줄었는지, 삼성 매출 비중이 80%를 넘는지(4Q25 85.5%처럼 연말 모듈 쏠림).
  • 반증: 3Q26 필리핀 부문 영업손실이 2Q -85억 이하로 개선되지 않고 연결 영업이익 < -60억이면 논지 폐기(기존 반증과 같은 방향, 부문 주석으로 원인 확인).
