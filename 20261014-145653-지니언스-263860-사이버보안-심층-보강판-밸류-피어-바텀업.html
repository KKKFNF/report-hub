§A. 원 리포트 평가 요약 (품질 68~72/100)

원 리포트(JD, 2026.5.21)의 뼈대:

  • 미토스 사태(Anthropic Claude 악용 AI 자동해킹, 26.4.7) → 글로벌 보안 수요 급증 → 한국 보안주 디커플링
  • NAC 국내 1위(점유율 71~75%), EDR 7년 연속 1위(46~49%)
  • 규제 cascade: EDR 의무화 → 공시대상 666→2,400개사 확대

강점: 디커플링 논리, 조달청 점유율 데이터, 2025 역성장을 정직하게 명시. 보강 전 약점 3가지 → 본 보강판에서 해소:

  1. 미토스 전제가 검증 불가 내러티브 → §B에서 base/upside 분리
  2. 목표주가 30,000원의 밸류 산식 부재 → §D 밸류 모델로 역산
  3. 경쟁사 비교 없음 → §C 피어 비교표

§B. 미토스 전제 분해 (Base vs Upside)

구분내용검증 상태
Base (실적 기반)해외 확장 가속 — 2026 상반기 매출 249억(YoY+118%), UAE 두바이 중동 거점, 글로벌 고객 200곳 돌파✅ DART 반기보고서·뉴스로 확인

해석: 원 리포트의 "미토스" 논지는 내러티브였으나 5개월 뒤 실적(매출 +118%)과 정책(제로트러스트)으로 Base화됨. 다만 10월 급등의 상당 부분은 테마성(앤트로픽 경고) 오버슈팅이 섞여 있어, 테마 소멸 시 변동성 주의.

  • ③ AI 양날의 검: AI가 보안 수요를 늘리지만, 동시에 보안 자동화로 레거시 NAC/EDR 벤더를 위협할 수도. (원 리포트 미반영 약점 → 중장기 모니터링 포인트)
  • ④ 매매 제약: 개별주식선물 미상장 → 현물만, 레버리지 불가. 형 주력인 선물 스윙 전략 적용 불가.
